## 图片来源与边界

截图基于 `eagle-plugin/index.html`、`js/v5-runtime.js` 的当前页面与交互渲染，合成、包装使用仓库 UI 示例数据；团队连接、命名、同步边界和诊断弹窗使用 `js/workbench.js` 中对应的生产渲染函数，以本地桩替代服务、文件和 Eagle 写入。维护页的筛选数量和更新页状态使用明确示例值。图中的预览为占位示意，并非生产素材。

`scripts/prepare-plugin-guide.py` 仅生成离线截图用的页面到忽略的 `data/manual-build/`，不调用 Eagle、不访问真实连接文件、不联网查询更新。需浏览器单独展示各状态、叠加编号并截图，不能把运行该脚本视为已重新生成全部图片。

截图与正文不得包含团队密钥、真实工程或聊天内容；图片不是 Eagle 宿主、NAS 并发、实际入库或飞书交付验收证据。团队配置、首次启动和现场验证仍以 `TEAM_DISTRIBUTION.md` 与 `STATUS.md` 为准。
