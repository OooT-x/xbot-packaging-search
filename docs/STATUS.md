## 已知风险与待确认项

- 当前仓库没有现有 X.bot 源码，需要在正式开发前确认是迁入旧服务还是新建服务。
- 首批真实素材目前只在 Eagle 描述中记录 `package_id`、`batch_id` 和 PNG/ZIP 配对 Eagle ID；SQLite 稳定映射尚未实现，暂不能视为机器人检索闭环已完成。
- Eagle 4.0 Web API V2 和当前 Folder Plugin API 没有文件夹删除方法；空批次清理暂时需要用户在 Eagle 界面完成，自动删除必须等待官方 API 支持或安全的插件能力。
- AE 辅助工具可以读取用户选中的合成名称，但不能自动判断哪些合成值得复用；包装合成仍需人工选择和分类。
- AE 的 `Reduce Project` 可能移除被表达式跨合成引用的内容，提取工具必须只处理副本并将这类引用列为人工复核项。
- 字体、第三方效果和示例素材不会因打包而自动获得授权或兼容性，入库前需要展示依赖警告。
- 核心文档存在版本库主版本和外部工作副本，修改后必须同步验证。
