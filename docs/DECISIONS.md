# 项目决策记录

本文件记录会影响多个模块或长期行为的决策。需求发生反复时，不删除旧记录；把旧决策状态改为“已取代”，并新增替代决策。

## 状态定义

- **有效**：当前必须遵循。
- **试行**：正在验证，可在复盘后调整。
- **已取代**：保留历史原因，但不再执行。
- **废弃**：确认不采用。

## D-001：项目名优先检索

- 日期：2026-08-18
- 状态：有效
- 决策：检索优先级以项目名称精确匹配和项目别名匹配为先，图片相似度只作为辅助召回方式。
- 原因：同一包装可能被多个项目复用，发送人通常记得项目名，但不一定知道准确包装名称。

## D-002：预览后确认再发送源文件

- 日期：2026-08-18
- 状态：有效
- 决策：机器人先返回 PNG 候选，只有原查询人回复候选消息确认后才发送 ZIP。
- 原因：降低模糊匹配、版本并存和群聊误确认导致的误发风险。

## D-003：Eagle 存素材，SQLite 存稳定映射

- 日期：2026-08-18
- 状态：有效
- 决策：Eagle 保存预览图和源文件；SQLite 保存项目、包装、版本、Eagle ID、源路径和 AE 合成名称之间的关系。
- 原因：文件名、位置和同名关系可能变化，不能作为唯一关联依据。

## D-004：源文件统一使用 ZIP

- 日期：2026-08-18
- 状态：有效
- 决策：发送包含 AE 工程及依赖素材的 ZIP，不发送裸 `.aep`。
- 原因：避免工程打开后缺少外部依赖。

## D-005：新查询必须明确提及机器人

- 日期：2026-08-18
- 状态：有效
- 决策：私聊和群聊中的新包装查询都必须明确 `@X.bot`；进入候选确认阶段后，原查询人回复时不需要再次提及。
- 原因：降低机器人噪音和群聊误触发。

## D-006：待入库目录按项目组织

- 日期：2026-08-19
- 状态：有效
- 决策：`00_待入库` 下每个项目建立一个文件夹，项目文件夹内同时放置该项目的 PNG 预览和 ZIP 源文件。
- 原因：项目是第一检索入口，同项目素材集中处理更符合实际入库习惯。

## D-007：Eagle 入库助手放到第五阶段

- 日期：2026-08-19
- 状态：有效
- 决策：Eagle 入库助手采用窗口插件形态，在第五阶段实现；插件负责入库和索引同步，不替代 X.bot 飞书服务。
- 原因：先完成文字检索闭环，再用已稳定的数据规则固化插件，减少过早自动化带来的返工。

## D-008：Git 中的核心文档为主版本

- 日期：2026-08-19
- 状态：有效
- 决策：`docs/飞书机器人包装素材检索项目文档.md` 为受版本控制的主版本，外部同名文档作为工作副本同步维护。
- 原因：长期项目需要可追溯的变更历史，同时保留用户原有文档使用位置。

## D-009：Eagle 数据只能通过官方 API 修改

- 日期：2026-08-19
- 状态：有效
- 决策：使用 Eagle Plugin API 或 Web API 修改目录、标签和素材，不直接编辑 `.library` 内部元数据文件。
- 原因：避免破坏资源库内部一致性，并保留清晰的操作边界。

## D-010：AE 包装提取是 Eagle 入库的前置环节

- 日期：2026-08-19
- 状态：有效
- 决策：第五阶段增加 AE 包装提取辅助工具。用户在 AE 中明确选择可复用合成后，工具在工程副本或收集副本上生成静态 PNG 预览、包含依赖的 ZIP、AE 收集报告和标准化 manifest，再交给 Eagle 入库助手审核。工具不得直接精简、改名或覆盖原工程。
- 原因：真实项目工程同时包含包装合成、业务画面、示例素材、字体和第三方效果。直接把项目目录导入 Eagle 会产生重复文件和错误映射；先在 AE 侧按合成提取和校验，才能得到可复用、可追溯的入库单元。

## D-011：本地项目文件夹对应一个待入库批次

- 日期：2026-08-19
- 状态：有效
- 决策：用户拖入或选择一个本地项目包装文件夹时，Eagle 入库助手在 `00_待入库` 下创建一个对应的批次文件夹。插件递归扫描源目录，但优先按 manifest 明确列出的路径导入；没有 manifest 时只识别符合待入库规则的预览 PNG 和源文件 ZIP。展开的 `.aep`、业务视频、截图、依赖图片和 Report 只用于校验，不原样镜像到 Eagle。每次导入生成稳定的 `batch_id`，重复导入必须提示复用、更新或新建批次，不能静默产生重复素材。
- 原因：按文件夹保留项目上下文更符合制作人员的交付习惯，但原样递归导入会把收集工程的展开目录、业务素材和 ZIP 同时导入，造成重复、噪声和误发风险。
