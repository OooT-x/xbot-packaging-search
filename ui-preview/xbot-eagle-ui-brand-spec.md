## 交互原则

1. 先选择任务，再进入单一流程；不同时展示所有模块。
2. 只显示当前步骤需要的输入、状态和主操作。
3. 技术细节、历史入口和诊断能力通过次级菜单或渐进展开访问。
4. 每个页面只保留一个主操作；危险或不可逆动作必须先预览再确认。
5. 当前选择和下一步持续显示在统一底部操作坞中。
6. 预览图缺失时使用明确占位，不伪造素材画面。
7. 首页新增包装区域同时承担点击选择与拖放识别；`.aep` 进入合成选择，文件夹或交付文件进入配对确认。
8. 配对预检卡片以 PNG ↔ ZIP 配对为主视觉；包装名称和包装类型属于主编辑动作，项目、版本、合成、目标目录与校验标签属于次要事实，默认收进可展开详情。

## 动效基线

- 按压反馈统一为 `120ms`，筛选、选中描边和颜色状态统一为 `180ms`，弹窗、抽屉与检查器展开统一为 `240ms`。
- 进入与反馈使用 `cubic-bezier(.23, 1, .32, 1)`；屏幕内连续移动使用 `cubic-bezier(.77, 0, .175, 1)`；侧边抽屉使用 `cubic-bezier(.32, .72, 0, 1)`。
- 配对卡片和已入库卡片共享蓝色边框与阴影反馈；配对卡片悬停不做位移，避免滚动区域裁切卡片上边框。
- 选择 AEP 合成或已入库包装时保留原列表节点，只更新选中态和检查器，避免整列闪切；检查器内容使用短距离淡入衔接上下文。
- 弹窗保持居中缩放淡入，抽屉从对应侧边进入；关闭速度快于打开，并在完成后恢复触发控件焦点。
- 键盘触发的高频操作不播放位移动画；系统或预览设置开启“减少动效”时移除位移，并将过渡压缩为近乎即时。

## 完整交互预览 v1

- 预览文件：`xbot-eagle-interaction-system-v1.html`
- 页面状态：任务首页、AEP 合成选择、配对预检、已入库管理、入库完成。
- 关键交互：统一阶段导航、AEP 结构选择、代表帧大图、PNG/ZIP 更换抽屉、包装类型修改与新增、风险确认、命名确认、素材修订和版本发布。
- 预览数据：页面内使用明确标注的演示数据和代表帧占位，不读取或写入 Eagle，不替换生产插件。
- 直接查看状态：在文件 URL 后追加 `#aep`、`#pair`、`#manage` 或 `#success` 可打开对应预览状态。

## 配对检查器预览 v2

- 预览文件：`xbot-eagle-interaction-system-v2.html`
- 配对页结构：左侧稳定配对列表，右侧固定检查器；PNG 是视觉主资产，ZIP 是关联交付文件。
- 主编辑动作：检查器内编辑包装名称、选择/新增包装类型、查看匹配证据、查看入库目标、替换 PNG/ZIP。
- 预览动作：点击 PNG 进入独立大图预览，点击 ZIP 查看文件信息；替换动作进入候选抽屉，不改变当前配对直到确认应用。

## 配对素材卡片预览 v3

- 预览文件：`xbot-eagle-interaction-system-v3.html`
- 卡片结构：预览图为主视觉，下方依次为包装名称、项目/类型/版本、PNG/ZIP 状态和配对状态，整体参考“已入库素材库”卡片。
- 交互结构：卡片点击打开配对检查器；搜索和状态筛选作用于卡片网格；卡片内不直接堆放名称、类型、替换等编辑控件。
- 直接查看检查器：在文件 URL 后追加 `#pair-detail` 可直接打开首个包装的配对检查器状态。

## 配对素材卡片对齐修复 v4

- 预览文件：`xbot-eagle-interaction-system-v4.html`
- 对齐规则：预览图使用独立容器和固定比例；选择框位于卡片右上角，不覆盖图片内容；选中态使用卡片外框表达。

## 配对素材卡片操作面板预览 v5

- 预览文件：`xbot-eagle-interaction-system-v5.html`
- 页面骨架：配对页不显示顶部步骤条和常驻检查器，使用全宽素材卡片网格；底部操作坞保持全宽固定。
- 选择规则：卡片右下角复选框只负责“纳入本次入库”，不再使用蓝色外框表达检查器选中状态。
- 二级面板规则：PNG、ZIP 与卡片右侧状态均为明确按钮；PNG/ZIP 分别进入素材更换面板，PNG 候选缩略图可继续打开大图预览，状态按钮进入问题与配对事实面板。卡片底部不重复显示处理状态。
- 名称与类型规则：包装名称使用卡片内无边框输入框直接修改，类型胶囊直接使用下拉选择；状态面板同时保留名称、类型、匹配依据与正式目录信息。
- 项目规则：配对页顶部提供批次级“项目名称”输入框；修改后同步卡片信息、搜索范围、配对事实、命名确认和最终入库摘要，空名称不会覆盖上一次有效值。
- 流程优化：任务首页保持当前结构；AEP 直接从工程信息进入合成结构，不显示顶部步骤条，并保留推荐交付默认筛选、折叠输出设置和可停止的收集进度；配对列表问题项优先并提供冲突筛选；已入库管理先判断修复当前版本、发布新版本、创建新包装或补充新类型，再进入对应动作。
- 动效对齐：AEP 树、合成检查器、已入库卡片、维护检查器、弹窗和替换抽屉统一采用“动效基线”；列表选择不再通过整页重绘制造闪切。
