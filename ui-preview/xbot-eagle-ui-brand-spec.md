## 交互原则

1. 先选择任务，再进入单一流程；不同时展示所有模块。
2. 只显示当前步骤需要的输入、状态和主操作。
3. 技术细节、历史入口和诊断能力通过次级菜单或渐进展开访问。
4. 每个页面只保留一个主操作；危险或不可逆动作必须先预览再确认。
5. 当前选择和下一步持续显示在统一底部操作坞中。
6. 预览图缺失时使用明确占位，不伪造素材画面。
7. 首页新增包装区域同时承担点击选择与拖放识别；`.aep` 进入合成选择，文件夹或交付文件进入配对确认。
